# Day 01 - SQL Basics

## Topics Covered

- SELECT
- WHERE
- ORDER BY
- SUM
- AVG
- GROUP BY

## Dataset

A small fictional sales dataset containing:

- Order information
- Customer names
- Product categories
- Quantity
- Price
- Region

## Questions Solved

1. Display all orders.
2. Find orders from Karachi.
3. Find orders where price is greater than 800.
4. Sort orders by price from highest to lowest.
5. Calculate total quantity sold.
6. Calculate average price.
7. Calculate total quantity sold for each category.
8. Calculate average price for each region.

## Key Learning

Practiced retrieving, filtering, sorting, and aggregating data using SQL.
