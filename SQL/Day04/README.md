# Day 04 - SQL INNER JOIN

## Topics Covered

- INNER JOIN
- ON
- Table aliases
- WHERE with JOIN
- GROUP BY with JOIN
- Aggregate functions with JOIN
- ORDER BY

## Tables Used

### sales

Contains:

- Order information
- Customer names
- Product categories
- Quantity
- Price
- Region

### customers

Contains:

- Customer ID
- Customer name
- Membership type
- Customer age

## Questions Solved

1. Display sales information with customer membership.
2. Display customer name, age, and order price.
3. Display Premium customers' orders.
4. Calculate total revenue by membership type.
5. Count orders by membership type.
6. Calculate average price by membership type.
7. Find Premium orders where price is greater than 800.
8. Calculate total quantity by membership type.
9. Display customer details sorted by price.
10. Display membership-wise revenue from highest to lowest.

## Key Learning

Learned how to combine two tables using INNER JOIN.

Practiced matching records using the ON condition.

Also practiced using WHERE, GROUP BY, aggregate functions,
and ORDER BY with JOIN.
