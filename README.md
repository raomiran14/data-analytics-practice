# 📊 Data Analytics Practice

> Daily hands-on practice building the core toolkit of a data analyst — SQL, Python, pandas, statistics, and Power BI — one focused session at a time.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## What This Is

Deliberate, structured skill-building: each day targets one analytics topic with a real dataset and a set of practice questions. No tutorials-on-repeat — every day ends with queries written from scratch.
